Before You Flash

Use a USB data cable and a browser with Web Serial support, such as desktop Chrome or Edge. Check your device model: chip detection cannot identify the board. Installing may erase device settings.

Full-flash images include the bootloader and partition table. Application binaries require an existing compatible installation. For older releases, download the full-flash image and select it when prompted.
