TRMNL firmware installer

Community builds of TRMNL firmware, straight from upstream release tags.

Choose your exact hardware target. Application binaries need an existing compatible installation; full-flash images include the bootloader and partition table.

Connect your device with a USB data cable and use a browser with Web Serial support, such as desktop Chrome or Edge. Installing may erase device settings. Select the exact board: chip detection cannot distinguish boards using the same chip.
